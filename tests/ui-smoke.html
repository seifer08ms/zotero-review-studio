模型 API 管理（独立配置，一键切换）

使用你的 ChatGPT 官网账号

通过 OpenAI 官方页面授权，符合条件的 ChatGPT Plus / Pro 账号可使用套餐用量，不需要 API Key。该功能不会读取网页版 Cookie 或 Codex 桌面客户端的凭据。

尚未连接。首次使用请点击“使用 ChatGPT 登录”。

授权会打开浏览器并返回 Zotero；登录后点击“测试当前 API”。仅向 OpenAI 官方 Responses API 发送你明确同意的内容；用量受 ChatGPT 套餐限制。

代理说明：每个 API 可以分别选“跟随 Zotero”、“强制直连”，或填写该 API 专属的 HTTP / SOCKS5 代理主机与端口。网络代理通过当前模型请求的 Gecko 通道实现，不会修改 Zotero 全局代理设置。另有可选 API 中转网关；网关不是 HTTP/SOCKS 代理，可能接触密钥和论文文本。当前版本不支持需账户密码认证的网络代理。
